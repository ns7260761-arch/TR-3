# 📌 Katalog Produk Responsif — KatalogPro

## 📖 Deskripsi Proyek
KatalogPro adalah website katalog produk responsif yang dibuat untuk memenuhi Tugas Rutin 3 mata kuliah Pemrograman Web, Pertemuan 3. Website ini menampilkan berbagai produk elektronik dengan desain modern dan responsif menggunakan HTML, CSS, Tailwind CSS, dan JavaScript.

## 🎯 Tujuan
- Membuat halaman katalog produk yang responsif.
- Menerapkan pendekatan mobile-first.
- Mengimplementasikan grid dan breakpoint responsif.
- Menampilkan informasi produk berupa gambar, nama, deskripsi, harga, dan tombol beli.
- Menguji tampilan website pada perangkat mobile, tablet, dan desktop.

## 🛠️ Teknologi yang Digunakan
- **HTML5** — membangun struktur halaman website.
- **Tailwind CSS** — mengatur layout, grid, warna, jarak, dan responsivitas.
- **CSS3** — mengatur animasi, efek hover, dan ukuran teks menggunakan `clamp()`.
- **JavaScript** — mengatur interaksi hamburger menu.
- **Font Awesome 6** — menampilkan ikon pada website.

## ✨ Fitur Website
1. **Responsive Navbar** — navigasi desktop dan hamburger menu pada perangkat mobile.
2. **Hero Section** — menampilkan judul dan tombol untuk melihat katalog.
3. **Katalog Produk** — menampilkan 8 produk elektronik.
4. **Responsive Grid** — menggunakan 1 kolom pada mobile, 2 kolom mulai 640px, 3 kolom mulai 768px, dan 4 kolom mulai 1024px.
5. **Product Card** — menampilkan gambar, nama produk, deskripsi, harga, dan tombol beli.
6. **Responsive Images** — ukuran gambar menyesuaikan breakpoint layar.
7. **Responsive Typography** — menggunakan fungsi CSS `clamp()`.
8. **Hover Effects** — memberikan efek visual saat kursor diarahkan ke kartu produk.
9. **Tentang dan Informasi Layanan** — menampilkan informasi kualitas produk, pengiriman, dan dukungan.
10. **Footer** — menampilkan tautan, informasi kontak, dan hak cipta.

## 📱 Pengujian Responsif
Pengujian direncanakan pada tiga ukuran layar berikut:

| Perangkat | Ukuran Layar |
|---|---|
| Mobile | 375 × 812 px |
| Tablet | 768 × 1024 px |
| Desktop | 1280 × 800 px |

Pengujian mencakup perubahan jumlah kolom produk, tampilan navbar, ukuran gambar, dan tipografi.

## 🚀 Cara Menjalankan
1. Download atau clone repository.
2. Buka folder proyek di Visual Studio Code.
3. Buka file `katalog.html` menggunakan browser atau ekstensi Live Server.
4. Pastikan koneksi internet tersedia agar Tailwind CSS CDN, Font Awesome, dan gambar produk dapat dimuat.
5. Ubah ukuran layar browser untuk menguji tampilan responsif.
